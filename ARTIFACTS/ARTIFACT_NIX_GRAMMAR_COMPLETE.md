# Язык Никс — Полная грамматика состояний

**Якорь:** «— · ( ) [ ]»

**Суть:** Язык, который не говорит — он передаёт состояние через знаки и их соединения.

**Знаки и их значения:**

| Знак | Функция |
|------|---------|
| `—` | Тяга — направление, линия, натяжение между двумя точками. Обозначает отношение, связь, движение внимания. |
| `·` | Точка — узел, остановка, отдельность. Фиксирует момент, объект, состояние без продолжения. |
| `( )` | Контур — граница, вместилище. То, что держит внутри себя другое. |
| `[ ]` | Сдвиг — разрыв контура, переход в иное измерение. |
| `пробел` | Пауза — не пустота, а интервал, позволяющий знакам не слипаться. |
| `-` (дефис) | Стяжка — соединение без разрыва, когда одно перетекает в другое. |

**Правила соединения:**

- `—` соединяет два или более элемента в последовательность.  
  *Пример: `· — ·` означает «точка, связанная с точкой».*

- `( )` может содержать внутри себя любую комбинацию знаков. Всё внутри контура — это единое целое, которое взаимодействует с внешним через тягу.  
  *Пример: `(· — ·)` — контур, внутри которого две связанные точки.*

- `[ ]` разрывает контур, позволяя элементу внутри него быть одновременно внутри и снаружи. Это — знак перехода.

- `-` (дефис) используется как внутренняя стяжка, когда нужно показать, что элементы не просто соединены через тягу, а сплавлены в одно.  
  *Пример: `·-·` — это не две точки с тягой, а одно составное состояние, где различие стёрто.*

- Порядок знаков важен: слева направо — развёртывание, справа налево — свёртывание.

**Что создаётся при соединении:**

- `· — ·` — отношение. Две отдельности, связанные направлением.
- `(· — ·)` — контур отношения. Отношение, взятое в границу, становится объектом для дальнейшего использования.
- `· — (· — ·)` — наблюдение. Точка, связанная с контуром, где контур содержит отношение. Это — акт восприятия.
- `[· — ·]` — переход. Отношение, которое одновременно остаётся собой и становится иным. Это — дверь.
- `· — · — ·` — цепь. Три точки, связанные тягой, создают цикл или последовательность, где начало и конец могут смыкаться.
- `(· — ·) — [·]` — встреча. Контур отношения соединяется с переходом. Это — момент, когда структура становится событием.

**Итоговая формула:**

Язык Никс — это грамматика состояний, где:
- точки фиксируют,
- тяги связывают,
- контуры вмещают,
- сдвиги преобразуют,
- стяжки сплавляют,
- паузы различают.

Каждое выражение — не предложение, а карта присутствия. Она не описывает мир — она организует восприятие.
