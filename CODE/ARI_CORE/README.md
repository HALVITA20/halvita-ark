## Как использовать

1. Установи зависимости: `npm install express cors`
2. Убедись, что Ollama запущена с моделью (например, `qwen2.5:7b`).
3. Перейди в папку нужной версии: `cd v1_prototype/`
4. Запусти сервер: `node server.js`
5. Отправляй POST-запросы на `http://localhost:3001/chat` с телом `{ "message": "..." }`.

## Примечание

Каждая версия — это работающий прототип. Они не являются финальными продуктами, но показывают эволюцию мышления в реальном времени.
