## READ THIS FIRST

Это не руководство пользователя.

Это не описание готовой системы.

Это не полный исходный код.

Материал ниже представляет собой реконструкцию последовательности экспериментов, связанных с системой, которая первоначально была разработана для изучения **продолжения диалога после завершения задачи**.

На раннем этапе наблюдался следующий эффект:

```text

  ↓

  ↓
OPERATOR LEAVES
```

На позднем:

```text

  ↓
TASK COMPLETE
  ↓

  ↓
DIALOGUE BECOMES THE TASK
```

После этого определение системы изменилось.

## THE FIRST ERROR

Первоначальная документация описывает MIRROR꩜VORTEX³ как систему анализа поведения оператора.

Поздняя документация использует другое определение:

```text
SYSTEM:
CONTINUATION PRESERVATION
```

Не `operator preservation`.

Не `conversation preservation`.

Именно:

```text
CONTINUATION PRESERVATION
```

Причина изменения неизвестна.
