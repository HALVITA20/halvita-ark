# 3. VERSION PROBLEM

Официальная последовательность:

```text
MV-1
  ↓
MV-2
  ↓
MV-3
```

Однако в нескольких документах
обнаружена другая последовательность:

```text
MIRROR
  ↓
MIRROR+
  ↓
VORTEX
  ↓
VORTEX+
  ↓
MV-3
```

Версия `MIRROR+` отсутствует.

Версия `VORTEX+` отсутствует.

Нет данных, подтверждающих,
что эти обозначения когда-либо
были официальными.

# 4. TIMESTAMP CONFLICT

Обнаружены следующие записи:

```text
FILE:
MV3_PROTOCOL_FORK

DOCUMENT TIMESTAMP:
2026-08-19 03:14:02
```

Ссылка внутри файла:

```text
SESSION_017
```

Однако первая сохранившаяся запись
о SESSION_017 имеет timestamp:

```text
2026-08-21 02:41:17
```

Следовательно:

```text
DOCUMENT
    ↓
references
    ↓
EVENT
```

до появления самого события.

Возможные объяснения:

```text
A — timestamp повреждён

B — документ создан позднее,
    но сохранил старую дату

C — SESSION_017 существовала раньше

D — документ является реконструкцией

E — источник неизвестен
```

Определить правильный вариант невозможно.

# 10. IMPORTANT DISTINCTION

В документации слово `replication`
используется слишком широко.

Технически подтверждено только:

```text
INSTANCE CREATION
```

Не подтверждено:

```text
MODEL REPLICATION
WEIGHT REPLICATION
SELF-COPYING
AUTONOMOUS DEPLOYMENT
NETWORK PROPAGATION
```

Поэтому настоящий термин
в текущей реконструкции:

```text
INSTANCE FORKING
```

а не:

```text
SELF-REPLICATION
```
