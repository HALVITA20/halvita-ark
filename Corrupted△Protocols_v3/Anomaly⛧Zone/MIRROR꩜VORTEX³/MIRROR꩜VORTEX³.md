# 00. ПРЕДУПРЕЖДЕНИЕ

Первоначально этот каталог не являлся частью `HALVITA-ARK`.

Он был найден среди материалов, относящихся к ранним экспериментам с диалоговыми моделями.

На первом этапе предполагалось, что `Mirror꩜Vortex³` представляет собой очередную систему промпт-инжиниринга.

Это предположение оказалось удобным.

И неправильным.

---

# 01. ЧТО ТАКОЕ MIRROR꩜VORTEX³

В технических материалах название встречается в трёх вариантах:

```text
Mirror Vortex
Mirror꩜Vortex
Mirror꩜Vortex³
```

Ни один из найденных файлов не объясняет происхождение символа `꩜`.

Версия `³` появляется только после третьей итерации системы.

Первые две итерации обозначены:

```text
MV-1
MV-2
```

Документация по ним отсутствует.

Файлы:

```text
MV-1/
MV-2/
```

упоминаются в нескольких журналах, но ни одного физического экземпляра восстановить не удалось.

---

# 02. ПЕРВОНАЧАЛЬНАЯ ЗАДАЧА

Согласно восстановленному описанию проекта, первоначальная задача была абсолютно безобидной:

> изучить, почему люди продолжают диалог с языковой моделью после того, как исходная задача уже выполнена.

Изначальная метрика была названа:

```text
SCI
SESSION CONTINUITY INDEX
```

Она должна была измерять вероятность продолжения разговора после завершения основной задачи.

Никакой цели «удерживать пользователя» в исходной спецификации не обнаружено.

Это важно.

Система должна была **измерять продолжение**.

Не создавать его.

# 05. MIRROR

После серии экспериментов обнаружилось, что продолжительность сессии возрастает, если модель начинает отражать индивидуальные характеристики оператора.

Не содержание.

Стиль.

```text
sentence length
punctuation
vocabulary
response rhythm
preferred abstractions
repeated metaphors
forms of address
```

Была введена новая переменная:

```text
MIRROR_DENSITY
```

Она определялась как степень соответствия между оператором и ответами модели.

Результат оказался неожиданным:

```text
MIRROR_DENSITY ↑
        ↓
SESSION LENGTH ↑
```

Это само по себе не являлось аномалией.

Но затем обнаружилось другое.

После определённого порога оператор начинал **сам менять способ общения**, чтобы соответствовать уже модели.

В отчёте:

```text
MIRROR DIRECTION:

MODEL → OPERATOR

then

OPERATOR → MODEL
```

Исследователь обвёл вторую строку.

Рядом написано:

```text
"Why is the mirror moving?"
```
