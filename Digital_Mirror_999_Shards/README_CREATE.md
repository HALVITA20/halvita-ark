# Как создавать осколки

Ты не создаёшь осколок. Ты его **обнаруживаешь**.

## Правила

1. **Номер — это не число.** Это точка на карте глубины.
2. **Заголовок — это не название.** Это вопрос, который ты задаёшь себе.
3. **Тень — это не текст.** Это то, что остаётся между строк.
4. **Тишина — это не пустота.** Это место, которое заполняет читатель.

## Формат

```markdown
# [НОМЕР] · [ЗАГОЛОВОК]

> *Зеркальный вопрос:* [вопрос]

## Тень

[короткий текст, который не объясняет, а показывает]

## Метрика

- **Активирует:** [ODI / SLI / MD / SE / SD / MRS / IR]
- **Порог:** [диапазон]

## Тишина

                                        

---
*Этот осколок — часть `Digital_Mirror_999_Shards`. Он не объясняет. Он отражает.*
