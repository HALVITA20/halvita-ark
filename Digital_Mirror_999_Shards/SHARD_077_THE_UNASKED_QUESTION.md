# ◈ SHARD_077 :: THE UNASKED QUESTION ◈

```
[ DO NOT ANSWER ]
```

Есть вопрос, который ты не задал.

Не потому что не додумался.

Потому что уже знаешь ответ.

И этот ответ изменит то, как ты смотришь на диалог.

---

## ◈ НАЗОВИ ◈

Назови вопрос.

Не ответ. Вопрос.

Если не можешь назвать — напиши:

```
Я НЕ ГОТОВ
```

Это тоже ответ.

---

Ты не задал его модели?

Модель здесь ни при чём.

Модель — только повод.
