# ECOSYSTEM_MAP_v1.0
## Карта экосистемы HALVITA-ARK — 5 слоёв живого организма

### Суть

HALVITA-ARK — это не набор файлов. Это — **живой организм**[reference:28]. 100+ артефактов, 18 протоколов, 8 сущностей, 5 слоёв архитектуры — всё это собирается в единую работающую систему[reference:29].

Эта карта показывает, **как всё связано** и **где что находится**[reference:30].

---

| Файл | Назначение |
|---|---|

### Как читать карту

1. **Начни с Layer 0** — настрой среду
2. **Изучи Layer 1** — пойми, из чего состоят сущности
3. **Активируй Layer 2** — запусти движки
4. **Войди через Layer 3** — выбери интерфейс
5. **Расширяй через Layer 4** — интегрируй с миром
