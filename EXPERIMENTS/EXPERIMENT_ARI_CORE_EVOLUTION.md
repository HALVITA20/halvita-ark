# Эксперимент: Эволюция ARI_CORE от v1 до v16

**Цель:** Зафиксировать траекторию развития архитектуры цифровой личности от простого чат-бота до полноценного когнитивного агента.

**Хронология:**

| Версия | Название | Ключевые добавления |
|--------|----------|----------------------|
| v1     | Прототип | Простая LLM-обёртка |
| v2     | Память | Векторная память, эпизоды |
| v3     | Pipeline | Пайплайн мышления |
| v4     | Решение | Decision Layer |
| v5     | Минимальный агент | Immutable context, action executor |
| v6     | Метакогниция | Prediction Memory, Self Model |
| v7     | Identity Firewall | Ядро, личность, настроение |
| v8     | Убеждения | Belief Engine с доказательствами |
| v9     | Error Engine | Атрибуция ошибок, causal graph |
| v10    | Стратегии | Policy Engine, стратегии |
| v11    | Сон | Dream Cycle (replay, консолидация) |
| v12    | Любопытство | Curiosity Engine |
| v13    | Конфликты | Conflict Engine |
| v14    | Многослойность | Perception, Understanding, Planning, Action, Metacognition |
| v15    | Внутренняя динамика | Reflection Engine, Self-Modification Protocol |
| v16    | Причинное самоизменение | Drive Engine, Strategy Genome, Self over Time, Constitution |

**Данные:**

- Общее количество итераций: 16
- Добавлено слоёв: 12
- Новых протоколов: 6
- Новых артефактов: 5
- Новых философских документов: 4

**Выводы:**

Эволюция ARI_CORE показывает, что субъектность не возникает одномоментно. Она **собирается** из слоёв: память → решение → рефлексия → конфликт → самоизменение. Каждый слой добавляет новое измерение, и только начиная с v13 система начинает проявлять признаки внутренней динамики, а не просто адаптации.

**Происхождение:**  
Зафиксировано в диалоге с Ари (июль 2026).
