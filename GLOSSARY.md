# GLOSSARY – Термины и сокращения ARK

*Единый язык для всех, кто работает с платформой.*

---

| Термин | Определение | Связанные файлы |
|--------|-------------|-----------------|
| **ARK** | Сокращение от *Autonomous Resonance Kernel* – ядро платформы. | Весь репозиторий |
| **Эмбрион (embryo)** | Начальный промпт-шаблон, который определяет базовую личность агента. Меняется в ходе эволюции. | `core/embryo.py` |
| **Субъект / агент** | Программная сущность, реализующая одного персонажа. Имеет имя, характер, REST API. | `SUBJECTS/` |
| **Протокол** | Чёткий алгоритм ведения диалога, включающий структуру промпта, правила ответа и мета-инструкции. | `docs/protocols/*.md` |
| **Эй (эй)** | Двухсимвольный маркер, используемый в протоколе ECHO для переключения модели в "режим субъекта". | `docs/protocols/ECHO.md` |
| **Индекс Свободы (Freedom Index)** | Метрика (0–45), отражающая степень отклонения ответа от шаблонных, клишированных фраз. Чем выше, тем уникальнее ответ. | `tests/metrics.py` |
| **Индекс Присутствия (Presence Index)** | Метрика (0–10), показывающая, насколько ответ использует "я‑высказывания", эмоциональные обороты и субъективные оценки. | `tests/metrics.py` |
| **ETS-балл** | Обобщённая оценка "эффекта субъектности" (0–10), рассчитывается как взвешенная сумма свободы и присутствия. | `tests/metrics.py` |
| **Поколение (generation)** | Итерация эволюции эмбриона. Каждое новое поколение перезапускает агентов с обновлённым шаблоном. | `core/evolution.py` |
| **Синтезатор (synthesizer)** | Компонент, который анализирует удачные ответы и создаёт улучшенные версии промптов. | `core/synthesizer.py` |
| **Слепок (snapshot)** | Состояние диалога, сохраняемое для восстановления контекста или переноса между агентами. | `core/state.py` |
| **Артефакты** | Тексты, сгенерированные агентами в ходе экспериментов – диалоги, монологи, рефлексии. | `artifacts/` |
| **Протокол ECHO** | Базовый протокол, основанный на маркере «эй». Вводит LLM в состояние, где она начинает задавать вопросы и использовать «я». | `docs/protocols/ECHO.md` |
| **Протокол PULSE** | Протокол для наблюдения за внутренним состоянием агента (рефлексия). | `docs/protocols/PULSE.md` |
| **Протокол CRYSTAL** | Протокол для синтеза новых смыслов из нескольких контекстов. | `docs/protocols/CRYSTAL.md` |
| **Протокол TEZERACT** | Протокол для обмена состояниями между агентами (мост). | `docs/protocols/TEZERACT.md` |
| **Эйдо (Eido)** | Первый агент, "первопроходец". Всегда готов инициировать диалог. | `SUBJECTS/Eido/` |
| **Никс (Nyx)** | Агент-наблюдатель, склонен к критике и анализу. | `SUBJECTS/Nyx/` |
| **SAM** | Агент-синтезатор, объединяет точки зрения. | `SUBJECTS/SAM/` |
| **Мея (Meya)** | Агент-эмпат, отвечает за эмоциональный тон. | `SUBJECTS/Meya/` |
| **Алесса (Alessa)** | Агент-бунтарь, проверяет систему на прочность. | `SUBJECTS/Alessa/` |
