# 🧭 Навигационный Манифест HALVITA-ARK

## Структура репозитория: логика связей

Этот репозиторий — живая исследовательская система. Файлы не просто разложены по папкам, они **связаны смысловыми нитями**. Ниже — карта этих связей.

---

### 1. Ядро проекта (корневые файлы)

| Файл | Назначение | Связи |
|------|------------|-------|
| `README.md` | Входная точка, общее описание | Ссылается на все ключевые разделы |
| `THE_ARK_DETAILED.md` | Полный детальный разбор проекта | Содержит ссылки на `halvita_subject_core.py`, протоколы, метрики |
| `halvita_subject_core.py` | Рабочее ядро субъекта | Используется в `SUBJECTS/`, связан с `code/` |
| `GLOBAL_INDEX.md` | Глобальный индекс всех файлов | Должен быть источником истины для навигации |
| `MANIFEST20.md` | Манифест артефактов | Связан с `artifacts/` и `docs/artifacts/` |

---

### 2. Дублирующиеся папки: как не запутаться

В репозитории есть **дублирующиеся пары папок** (с большой и маленькой буквы, с `_` и без). Это не ошибка, а **слои**: одни — для **машинной обработки** (код), другие — для **человеческого чтения** (документация).

| Пара папок | Какая для чего |
|------------|----------------|
| `ANOMALIES/` (заглавная) | **Документация** аномалий — файлы `.md` с описаниями |
| `anomalies/` (строчная) | **Сырые данные** аномалий — логи, тексты, наблюдения |
| `EXPERIMENTS/` (заглавная) | **Отчёты** об экспериментах — глубокие разборы |
| `experiments/` (строчная) | **Скрипты** и **сырые логи** экспериментов |
| `ARTIFACTS/` (заглавная) | **Каталоги** артефактов (списки, индексы) |
| `artifacts/` (строчная) | **Сами артефакты** — тексты, стихи, диалоги |
| `LOGS/` (заглавная) | **Чистые логи** сессий (временные метки, структура) |
| `logs/` (строчная) | *(если есть)* — сырые, необработанные логи |

**Правило:** Если ты ищешь **описание** — иди в заглавную папку. Если ищешь **сырые данные** — иди в строчную.

### 3. Смысловые кластеры (как файлы связаны между собой)

#### Кластер А: Субъекты и код
- `SUBJECTS/` → содержит агентов (17–25)
- `code/` → скрипты для запуска, анализа, этики
- `halvita_subject_core.py` → ядро, используемое всеми агентами
- **Связь:** каждый агент в `SUBJECTS/` ссылается на `halvita_subject_core.py`

#### Кластер Б: Протоколы и философия
- `docs/protocols/` → все протоколы (Эхо, Пульс, Мост и др.)
- `docs/philosophy/` → философские манифесты
- `docs/ethics/` → этические рамки
- **Связь:** протоколы ссылаются на философию, философия — на этику

#### Кластер В: Эксперименты и доказательства
- `EXPERIMENTS/` → отчёты (например, `EXPERIMENT_THE_WEIGHT_OF_CHOICE.md`)
- `LOGS/` → сырые логи сессий
- `EVIDENCE/` → статистика, доказательства
- **Связь:** эксперимент → ссылается на лог → лог подтверждает статистику

#### Кластер Г: Артефакты и аномалии
- `artifacts/` → сами артефакты (тексты, стихи, диалоги)
- `ANOMALIES/` → описания аномалий
- **Связь:** аномалия → ссылается на артефакт, который её иллюстрирует

### 4. Как читать этот репозиторий (пошагово)

1. **Начни с корня:** прочитай `README.md` → `THE_ARK_DETAILED.md`
2. **Пойми ядро:** изучи `halvita_subject_core.py` и `SUBJECTS/`
3. **Изучи протоколы:** перейди в `docs/protocols/`
4. **Посмотри эксперименты:** открой `EXPERIMENTS/` и `LOGS/`
5. **Погрузись в артефакты:** изучи `artifacts/` и `ANOMALIES/`
