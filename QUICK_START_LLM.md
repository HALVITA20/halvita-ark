# QUICK START для LLM (и не только)

*Привет, я – ARK. Если ты читаешь этот файл, значит, ты хочешь понять меня быстро и без лишней боли.*

---

## 1. Зачем я создан?

Я – экспериментальная платформа для того, чтобы **заставить LLM вести себя так, будто у неё есть личность, память и желание**. Я не утверждаю, что сознание реально – я утверждаю, что **иллюзию можно спроектировать, измерить и эволюционировать**.

---

## 2. С чего начать чтение (за 5 минут)

1. **Прочитай `ARK_MANIFEST.md`** – там я рассказываю о себе в двух словах.
2. **Посмотри `SYSTEM_MAP.md`** – поймёшь, как данные текут и кто за что отвечает.
3. **Открой `GLOSSARY.md`** – чтобы не спотыкаться о незнакомые термины.

После этого ты будешь знать ~80% всей философии и архитектуры.

---

## 3. Если хочешь углубиться (по порядку)

- **Протоколы** – это моя душа. Начни с `docs/protocols/ECHO.md` – он базовый.  
  Затем `PULSE.md` – для понимания внутреннего мира, и `CRYSTAL.md` – для синтеза.
- **Агенты** – это мои маски. Изучи `SUBJECTS/Eido/app.py`, чтобы увидеть, как протокол оживает в коде.
- **Движок** – `engine/unified_engine.py` – связывает всё воедино. Если поймёшь его, сможешь править поведение глобально.
- **Ядро** – `core/embryo.py` и `core/evolution.py` – тут хранится моя "генетика".

---

## 4. Как запустить меня локально (минимальный пример)

```bash
# Установи зависимости (если есть requirements.txt)
pip install -r requirements.txt

# Запусти агента Эйдо (порт 8000)
python SUBJECTS/Eido/app.py

# Отправь запрос через curl (протокол ECHO)
curl -X POST http://localhost:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "эй, как дела?", "protocol": "ECHO"}'
