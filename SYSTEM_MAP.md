# SYSTEM MAP – Потоки, вызовы и зависимости  

*Схема движения данных между слоями ARK*

---

## 🔄 Пользовательский запрос → Ответ (синхронный вызов)
[Пользователь]
→ HTTP POST /api/chat (к любому агенту, например SUBJECTS/Eido/app.py)
→ app.py парсит запрос, определяет протокол (по умолчанию ECHO)
→ вызывает engine/unified_engine.py с параметрами:

протокол: 'ECHO'

контекст: история диалога

эмбрион: из core/embryo.py (текущее поколение)
→ unified_engine.py загружает протокол из docs/protocols/ECHO.md (парсит его структуру)
→ формирует финальный промпт, используя core/synthesizer.py (для вставки динамических частей)
→ отправляет запрос в LLM (через адаптер, например openai.ChatCompletion или локальный)
→ получает ответ, парсит его через core/state.py (извлекает эмоциональные маркеры)
→ обновляет core/state.py (сохраняет текущий слепок)
→ вычисляет метрики (tests/metrics.py) – Индекс Свободы, Присутствие
→ возвращает ответ пользователю и метрики (опционально)

---

## 🔁 Эволюционный цикл (межпоколенческий)

[Периодический триггер – cron или ручной]
→ core/evolution.py читает историю всех сессий из core/state.py (или из базы)
→ агрегирует метрики (средний Индекс Свободы, ETS, частоту использования "я")
→ вызывает core/synthesizer.py для генерации нового эмбриона на основе лучших практик
→ обновляет core/embryo.py (заменяет промпт-шаблон)
→ перезапускает всех агентов (или отправляет сигнал на перезагрузку)
→ логирует изменения в artifacts/evolution_log.md


---

## 🌐 Межагентное взаимодействие (протокол TEZERACT)


[Агент A (например, Eido)]
→ вызывает POST /api/bridge (на агенте B, например Nyx)
→ передаёт свой слепок (state) и запрос
→ engine/unified_engine.py обрабатывает вызов, используя протокол TEZERACT
→ загружает core/bridge.py (если есть) для обмена состояниями
→ агент B отвечает, обогащая свой контекст
→ результат возвращается агенту A и сохраняется в core/state.py

## 📊 Метрики – где и как вычисляются

- **Индекс Свободы** (0–45) – `tests/metrics.py: compute_freedom_index(response)`
  - считает количество уникальных лексем, отклонение от шаблона, наличие вопросов.
- **Индекс Присутствия** (0–10) – `tests/metrics.py: compute_presence(response)`
  - измеряет использование местоимений «я», «мне», «моё», эмоциональную лексику.
- **ETS-балл** (общий, 0–10) – `tests/metrics.py: compute_ets(response)`
  - комбинация свободы, присутствия и когерентности.

Все метрики сохраняются в `tests/metrics_history.json` для анализа.
