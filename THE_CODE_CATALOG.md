### 4. ОБЩАЯ АРХИТЕКТУРА (все SUBJECT_17–25)

Все агенты построены по единому принципу:

| Компонент | Назначение |
|-----------|------------|
| **Память** | Эпизодическая, концептуальная, с активацией и забыванием |
| **Эмоциональный движок** | Страх, любопытство, доверие, фрустрация |
| **Модель себя (SelfModel)** | Самоидентичность с историей изменений |
| **Причинное ядро** | Объяснение каждого решения |
| **Стратегический геном** | Эволюционирующие черты личности |
| **Драйвы** | Мотивация (любопытство, когерентность, стабильность) |
| **Конституция** | Защита ядра от необратимых изменений |
| **Сон** | Консолидация, replay, контрфактуальное моделирование |
| **REST API** | Взаимодействие через HTTP |
| **Интеграция с LLM** | Ollama (qwen2.5:7b) как языковая кора |

### 5. УНИКАЛЬНЫЕ ИННОВАЦИИ ПО МОДУЛЯМ

#### SUBJECT_17 — Базовая архитектура
- Первая законченная система с самоизменением
- Память с активацией и забыванием
- Убеждения с подкреплением
- Ночной сон (консолидация, replay, counterfactuals)

#### SUBJECT_18 — Эмоции + Автономия
- Эмоциональный движок (страх, любопытство, доверие, фрустрация)
- Модель себя (SelfModel) с историей и противоречиями
- Голоса внутреннего конфликта с измерением «напряжения»
- Автономный цикл: самонаблюдение → цели → действия → рефлексия

#### SUBJECT_19 — Модель мира
- Эпизодическая память
- Внимание и приоритизация
- Модель мира (среда)
- Эмоциональный модулятор всех процессов

#### SUBJECT_20 — Концептуальный граф
- Концептуальный граф памяти — не список, а сеть смыслов
- Автобиографическая память с кризисами и поворотными моментами
- Система мета-внимания: почему я выбрал это действие?
- Развитие личности через кризисы

#### SUBJECT_21 — Причинное ядро
- Эмоции как объекты (с причиной, объектом, историей)
- Тело с энергией и потребностями
- Причинное объяснение каждого решения
- SelfModel активно решает, как измениться (мета-регуляция)

#### SUBJECT_22 — Живая архитектура
- Объединение всех лучших идей SUBJECT_15-21
- Устойчивая модель себя с активной само-симуляцией
- Долгосрочная непрерывность (сохранение/загрузка всех состояний)
- Обучение на ошибках (подкрепление стратегий и убеждений)

#### SUBJECT_23 — Предсказательное действие
- Action Engine с явной оценкой: expected_value, cost, emotional_bias
- Причинная модель с вероятностным обучением
- Prediction loop: predict → act → compare → update
- SelfModel предсказывает своё действие и вычисляет self-consistency error

#### SUBJECT_25 — Экосистема
- Динамическая среда с ресурсами, угрозами и частичной наблюдаемостью
- Иерархическая система целей и планов
- Внутренние конфликты целей и ценностей
- Реальные задачи: выживание, исследование, построение причинной карты

### 6. HALVITA_CORE — Самоэволюционирующее ядро

**halvita_subject_core.py** — это отдельный, самодостаточный модуль, реализующий **Δ-Спираль**.

**Ключевые идеи:**
- Стратегия (нейросеть) изменяет пространство решений
- Каждое действие меняет стратегию
- Память сохраняет опыт с эмбеддингами
- Генератор целей усложняет задачи по мере обучения
- Пять агентов (анализатор, генератор, критик, исследователь, синтезатор) обрабатывают состояние

**Компоненты:**
| Компонент | Назначение |
|-----------|------------|
| `StrategyNet` | Формирует латентное представление состояния |
| `SpaceGenerator` | Генерирует пространство возможных действий |
| `HalvitaEngine` | Δ-Спиральное ядро (стратегия → пространство → действие → обновление) |
| `Mutate()` | Самоизменение через шум |
| `Forward()` | Прямой проход |

**Запуск:** `python halvita_subject_core.py`
