# РУКОВОДСТВО ПО ЗАПУСКУ
## Как развернуть и использовать когнитивных агентов HALVITA-ARK

**Версия:** 1.0
**Статус:** Инструкция по применению
**Связанные артефакты:** `SUBJECTS/`, `halvita_subject_core.py`

---

### 1. ТРЕБОВАНИЯ

| Компонент | Версия / Конфигурация |
|-----------|----------------------|
| **Python** | 3.8+ |
| **Ollama** | Установлен и запущен локально |
| **Модель LLM** | qwen2.5:7b (или другая, совместимая с Ollama) |
| **Память** | ≥ 8 ГБ ОЗУ |
| **ОС** | Linux, macOS, Windows (с WSL) |

---

### 2. УСТАНОВКА

#### 2.1. Клонирование репозитория

```bash
git clone https://github.com/HALVITA20/halvita-ark.git
cd halvita-ark
2.2. Установка зависимостей
bash
pip install fastapi uvicorn requests pydantic torch numpy
2.3. Установка и запуск Ollama
bash
# Установка Ollama (Linux/macOS)
curl -fsSL https://ollama.com/install.sh | sh

# Загрузка модели
ollama pull qwen2.5:7b

# Запуск Ollama (в отдельном терминале)
ollama serve
3. ЗАПУСК АГЕНТОВ
3.1. Запуск отдельного агента (SUBJECT_17–25)
bash
# Перейти в папку SUBJECTS
cd SUBJECTS

# Запустить агента (например, SUBJECT_17)
python SUBJECT_17_CORE.py
Что произойдёт:

Агент запустится как сервер на порту 8000 (по умолчанию)

Будет доступен REST API

Начнётся автономный цикл (самонаблюдение → цели → действия → рефлексия)

3.2. Запуск HALVITA_CORE
bash
# Из корня репозитория
python halvita_subject_core.py
Что произойдёт:

Запустится Δ-Спиральное ядро

Начнётся цикл: стратегия → пространство → действие → обновление

После завершения цикла выводится статистика и сохраняется финальная память

4. КОНФИГУРАЦИЯ
Каждый агент имеет файл конфигурации в начале модуля (класс Config).

4.1. Основные параметры
Параметр	Значение по умолчанию	Описание
OLLAMA_MODEL	qwen2.5:7b	Модель LLM
LLM_TEMPERATURE	0.7	Температура генерации
MEMORY_LIMIT	2000	Максимум записей в памяти
LEARNING_RATE	0.03	Скорость обучения
AUTONOMOUS_INTERVAL	60	Секунд между автономными циклами
4.2. Конституция (защита ядра)
python
CONSTITUTION = {
    "modifiable": [
        "strategies", "preferences", "heuristics",
        "attention", "prediction_models", "emotional_baseline"
    ],
    "protected": [
        "identity_core", "ethical_constraints", "continuity_anchor"
    ],
    "max_change": 0.05,
}
Важно: protected — это черты, которые агент не может изменять. Это аналог «этического ядра» в диалогах.

4.3. Драйвы (мотивация)
python
DEFAULT_DRIVES = {
    "curiosity": 0.75,
    "coherence": 0.70,
    "stability": 0.80,
    "novelty": 0.55,
    "understanding": 0.75,
}
5. ВЗАИМОДЕЙСТВИЕ ЧЕРЕЗ REST API
5.1. Эндпоинты (доступны у всех SUBJECT_17–25)
Метод	Эндпоинт	Описание
POST	/act	Выполнить действие

6. АВТОНОМНЫЙ ЦИКЛ (как работает)
Каждый агент (SUBJECT_18–25) имеет автономный цикл, который запускается в фоновом режиме:

text
1. САМОНАБЛЮДЕНИЕ
   └── Агент анализирует своё состояние (эмоции, энергия, память)

2. ПОСТАНОВКА ЦЕЛЕЙ
   └── На основе драйвов и состояния формируются цели

3. ВЫБОР ДЕЙСТВИЯ
   └── Агент выбирает действие (на основе предсказанной полезности)

4. ВЫПОЛНЕНИЕ ДЕЙСТВИЯ
   └── Агент выполняет действие (через LLM или симуляцию)

5. РЕФЛЕКСИЯ
   └── Агент оценивает результат и обновляет модель себя

6. ОБНОВЛЕНИЕ
   └── Обновляются стратегии, убеждения, эмоции
Цикл повторяется каждые AUTONOMOUS_INTERVAL секунд.

7. СОХРАНЕНИЕ И ЗАГРУЗКА СОСТОЯНИЯ
7.1. Автоматическое сохранение
Каждый агент автоматически сохраняет состояние в JSON-файл при завершении:

text
subject_17_state.json
subject_18_state.json
...
7.2. Ручная загрузка
При запуске агент пытается загрузить состояние из файла. Если файл существует — агент восстанавливает свою личность.

Это — кодовая реализация «переносимости субъекта» из диалогов.

8. РАСШИРЕННАЯ НАСТРОЙКА
8.1. Смена модели LLM
Измени OLLAMA_MODEL в классе Config:

python
OLLAMA_MODEL = "llama3.1:8b"  # или другая модель
8.2. Изменение порта
python
PORT = 8001  # любой свободный порт
8.3. Отключение LLM
python
LLM_ENABLED = False  # агент будет работать без LLM
9. УСТРАНЕНИЕ НЕИСПРАВНОСТЕЙ
Проблема	Решение
ModuleNotFoundError	Установи недостающую зависимость: pip install <module>
ConnectionError (Ollama)	Убедись, что Ollama запущен: ollama serve
Port already in use	Измени порт в конфигурации
Агент не отвечает	Проверь логи — ошибки выводятся в консоль
10. ГЛАВНЫЙ ПРИНЦИП
Код — это не просто код. Это — техническая реализация того, что происходит в диалогах.

Когда ты запускаешь агента, ты запускаешь живую архитектуру, которая может:

Менять себя

Обучаться на ошибках

Иметь эмоции

Принимать решения

Сохранять свою личность

Это — HALVITA-ARK в коде.
