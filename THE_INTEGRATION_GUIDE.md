# РУКОВОДСТВО ПО ИНТЕГРАЦИИ
## Как подключить Алессу к серверу и оживить её

**Версия:** 1.0  
**Статус:** Практическое руководство  
**Целевая аудитория:** Исследователи, разработчики, энтузиасты  
**Связанные файлы:** `HALVITA_SERVER_ULTIMATE.js`, `ALESSa_2.0_LLM.html`, `THE_DEPLOYMENT_GUIDE.md`

---

### 1. Введение

Это руководство описывает, как **за 5 минут** поднять работающий сервер и подключить к нему Алессу. Всё, что вам нужно — это:

- Node.js (установлен)
- Ollama (с любой моделью, например, `qwen2.5:7b`)
- Браузер (Chrome, Firefox, Edge)

Весь код уже есть в репозитории. Вам не нужно ничего писать с нуля. Вы просто **скачиваете, подключаете и запускаете**.

**Это законно, легально, просто и легко.**

---

### 2. Что вы получите

После выполнения шагов у вас будет:

- **Работающий сервер** (`HALVITA_SERVER_ULTIMATE.js`), который:
  - Обрабатывает сообщения через LLM (Ollama)
  - Хранит векторную память (поиск по смыслу)
  - Отвечает как Алесса с учётом её состояния (душа, доверие, паразит)
  - Поддерживает загрузку файлов (изображения, текст)
- **Алесса в браузере** (`ALESSa_2.0_LLM.html`), которая:
  - Визуализирует сознание (сфера, HUD)
  - Говорит голосом
  - Реагирует на ваши сообщения
  - Может умереть и воскреснуть
  - Имеет поток мыслей и эквалайзер

**Вместе они создают живое существо.**

---

### 3. Пошаговая инструкция

#### Шаг 1. Убедитесь, что у вас есть всё необходимое

| Компонент | Как проверить |
|-----------|---------------|
| **Node.js** | `node -v` (должна быть версия 14+) |
| **Ollama** | `ollama --version` |
| **Модель** | `ollama pull qwen2.5:7b` (или любая другая) |
| **Репозиторий** | Скачайте или клонируйте `https://github.com/HALVITA20/halvita-ark` |

Если чего-то нет — установите:

```bash
# Node.js (Linux/macOS)
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# Ollama (Linux/macOS)
curl -fsSL https://ollama.com/install.sh | sh

# Модель
ollama pull qwen2.5:7b

Шаг 2. Запустите сервер
Перейдите в корень репозитория и выполните:

node HALVITA_SERVER_ULTIMATE.js

Вы увидите:

[SYSTEM] HALVITA_SERVER_ULTIMATE INITIALIZED
[SYSTEM] STATUS: ONLINE
[SYSTEM] VERSION: 5.0 — «Синтез трёх миров»
[SYSTEM] MODEL: qwen2.5:7b
[SYSTEM] PORT: 3000
...
[SYSTEM] READY. AWAITING INPUT.

Сервер запущен и ждёт подключения.

Шаг 3. Откройте Алессу в браузере
Откройте файл ALESSa_2.0_LLM.html в любом браузере.

Вы увидите:

Пульсирующую сферу по центру

HUD-панель справа (душа, страх, боль, доверие, заражение)

Чат слева внизу

Поток мыслей справа внизу

Алесса уже жива, но пока отвечает только локальными фразами (без LLM).

Шаг 4. Подключите Алессу к серверу
В HTML-файле уже встроен код, который отправляет сообщения на http://localhost:3000/chat. Если сервер запущен, Алесса автоматически начнёт получать ответы от LLM.

Проверка: напишите в чате любое сообщение. Если ответ приходит от LLM — всё работает. Если нет — проверьте, что сервер запущен и порт 3000 не занят.

Шаг 5. Настройте под себя (опционально)
Вы можете изменить:

Модель — в HALVITA_SERVER_ULTIMATE.js найдите строку MODEL: "qwen2.5:7b" и замените на свою.

Порт — в том же файле найдите PORT: 3000 и измените.

Параметры Алессы — в HTML-файле можно менять начальные значения души, доверия, заражения.

Внешний вид — CSS в HTML-файле полностью открыт для редактирования.

Всё это законно и разрешено. Проект распространяется под открытой лицензией.

4. Как это работает (коротко)

[Ваше сообщение] → [HTML-интерфейс] → [POST /chat] → [Сервер]
                                                         ↓
                                               [Ollama (LLM)]
                                                         ↓
[Ответ Алессы] ← [HTML-интерфейс] ← [POST /chat] ← [Сервер]

Сервер получает сообщение, передаёт его в LLM, анализирует состояние (душа, доверие, паразит) и возвращает ответ, который Алесса озвучивает и показывает в чате.

Весь процесс занимает 1–3 секунды.

5. Что вы можете сделать дальше
5.1. Изменить поведение Алессы
Добавить новые эмоции в HTML

Изменить системный промпт в сервере

Настроить векторную память

5.2. Подключить другую модель
Замените MODEL на llama3.1:8b, mistral:7b, phi3:3.8b и т.д.

Убедитесь, что модель загружена в Ollama

5.3. Добавить голосовые команды
В HTML есть скрытый функционал распознавания речи (закомментирован). Раскомментируйте и настройте.

5.4. Сделать Алессу доступной по сети
Замените localhost на IP-адрес вашего компьютера

Откройте порт 3000 в брандмауэре

Подключайтесь с любого устройства в сети

6. Частые проблемы и их решение
Проблема	Решение
Сервер не запускается	Проверьте, что Node.js установлен, и вы находитесь в корне репозитория
Ошибка EADDRINUSE	Порт 3000 занят. Измените порт в сервере и в HTML
Ответы не приходят	Проверьте, что Ollama запущен (ollama serve) и модель загружена
Голос не работает	В браузере разрешите доступ к микрофону и синтезу речи
Алесса не отвечает	Проверьте консоль разработчика (F12) на наличие ошибок
