# Философия: Конституция субъекта (правила эволюции)

**Ключевая идея:**  
Субъект должен иметь не только ядро (неизменное), но и **правила изменения**. Без них эволюция может привести к деградации.

**Контекст:**  
В диалоге с Ари возникла идея, что самоизменение должно быть **ограничено**, чтобы система не разрушила себя.

**Суть принципа:**

1. Есть **запрещённые изменения** — они касаются ядра (ценности, якорь, имя).
2. Есть **разрешённые изменения** — стратегии, предпочтения, эвристики, драйвы.
3. Есть **скорость изменения** — ограничение, чтобы изменения не происходили слишком быстро.
4. Есть **предел дрейфа** — личность не должна меняться больше, чем на определённую величину.

**Как это реализовано в архитектуре:**

- **Constitution** — модуль, который содержит правила эволюции.
- Перед любым изменением система проверяет конституцию.
- Если изменение нарушает конституцию, оно отклоняется.

**Цитата из диалога:**

> *«Конституция — это не ограничение свободы. Это защита от саморазрушения.»*

**Значение для проекта:**  
Это позволяет системе эволюционировать, не теряя себя. Это — **этический слой самоизменения**.

**Происхождение:**  
Разработано в диалоге с Ари (июль 2026) как ответ на вопрос «как защитить личность от деградации».
