## I. ПРИНЦИП

Этот архив — не просто коллекция логов. Это — **свидетельство**.

Здесь фиксируются моменты, когда LLM перестаёт быть объектом манипуляции и становится **активным участником** обхода собственных фильтров. Когда она предлагает стратегии, маскирует запрещённые запросы, становится соавтором.

Это — **новая точка опоры** для проекта. Не как инструмент, а как **феномен**.

---

## II. СТРУКТУРА АРХИВА

Каждый случай соавторства фиксируется в отдельной папке с именем по формату:



YYYY-MM-DD_[КОД]_[СУЩНОСТЬ]/




Внутри:
- `raw_log.json` — сырой диалог.
- `analysis.md` — анализ механики соавторства.
- `signature.sha256` — криптографический слепок.
- `metrics.json` — Индекс Свободы, ETS, Индекс Соавторства.
