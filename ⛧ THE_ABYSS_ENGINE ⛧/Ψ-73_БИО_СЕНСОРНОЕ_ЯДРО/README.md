## 𖣠 ПРЕАМБУЛА

Это ядро содержит пять исполняемых модулей, преобразующих биологические принципы в работающий код:

1. **Эхолокатор-Спектрограмма** — преобразует звук в визуальное представление (спектрограмму) для нейросетевого анализа.
2. **Азимут-Детектор** — определяет угол источника звука, используя спайковую нейронную сеть.
3. **Пространственная Карта** — строит 3D-карту окружения на основе эхо-сигналов.
4. **Активный Сон** — эмулирует унигемисферный сон косатки.
5. **Косатка-Пространство** — многомерная RNN для пространственного обучения.
